# 🌍 AQI Analysis Dashboard

An interactive Air Quality Index (AQI) dashboard created using Microsoft Power BI to analyze air quality across different cities and states.

## 🛠️ Tools Used
- Power BI
- DAX
- Data Analysis & Visualization

## 📊 Dashboard Includes
- AQI by City & State
- AQI Category Distribution
- Average AQI Trend
- Maximum AQI
- Unsafe Readings
- Interactive Filters

## 🎯 Objective
To analyze air quality patterns and present meaningful insights through an interactive dashboard.
